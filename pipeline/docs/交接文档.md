## 四、下载环节（Xiaoer 扩展 + daemon + 监控页）

### 4.1 Chrome 扩展（Xiaoer VideoLab v1.6.3）

- 加载：`chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 选 `~/xiaoer-videolab/extension/`。
- 用法：打开视频页 → 点工具栏扩展图标 → 弹窗点「下载视频」。
  - 抖音/小红书：`grab` 脚本注入页面读取正在播放的流地址 → daemon `/download-direct`（curl + Referer，绕过 a_bogus 反爬）。
  - 其余站点（YouTube 等）：直接 POST daemon `/download`（yt-dlp）。
- **修改扩展代码后必须在 `chrome://extensions` 点「重新加载」**，否则跑旧代码（这是历次"改了没生效"的头号原因）。

### 4.2 下载 daemon（127.0.0.1:7788）

**环境变量**（plist `EnvironmentVariables` 中设置）：

| 变量 | 当前值 | 说明 |
|---|---|---|
| `VIDEOLAB_PORT` | 7788 | 监听端口（仅 127.0.0.1） |
| `VIDEOLAB_DOWNLOADS` | `/Users/limingyu/视频自动搬运发布/生肉视频` | 下载目录 |
| `VIDEOLAB_YT_DLP` | `/opt/homebrew/bin/yt-dlp` | yt-dlp 路径 |
| `VIDEOLAB_PREFIX` | 空 | 文件名前缀 |
| `VIDEOLAB_MAX_HEIGHT` | 1080 | 最大高度 |
| `VIDEOLAB_COOKIES_BROWSER` | 空 | **保持空！** 填 chrome 会触发反爬 |
| `VIDEOLAB_APP_NAME` | Xiaoer VideoLab | 桌面通知名称 |

**下载行为**：
- 文件名 `平台_标题_日期.ext`（平台由 URL host 识别：抖音/小红书/B站/YouTube/微博/知乎/西瓜/X/Vimeo/Instagram/TikTok/快手/优酷/爱奇艺/Facebook/Reddit/Dailymotion）。
- 代理：YouTube/TikTok/X/Vimeo/Instagram/Facebook/Reddit/Dailymotion 自动加 `--proxy http://127.0.0.1:7897`；抖音/小红书直连（`--noproxy *`）。
- yt-dlp 参数：`--no-playlist --playlist-items 1 --socket-timeout 30 --no-mtime`、`-f bv*[height<=1080][ext=mp4]+ba[ext=m4a]/...`、`--merge-output-format mp4`；完成/失败写 history JSONL；桌面通知（macOS osascript）。

**API**：

| 接口 | 说明 |
|---|---|
| `POST /download` | `{url, filename?}`；`filename` 用于续传（精确名）；返回 202；同一 URL 已有活跃进程时返回 `{"queued":true,"duplicate":true}` 不重复下载 |
| `POST /download-direct` | `{url, referer, filename, pageUrl}` 抖音/小红书直连下载 |
| `POST /cancel` | `{url}` 或 `{path}`；按文件路径取消；**静默**：不写 failed 历史，`.part` 保留 |
| `POST /history-delete` | `{url}` 删一条，`{clear:"all"}` 或 `{clear:"failed"}` 批量清 |
| `GET /history` `GET /health` `GET /probe?url=` | 历史 / 健康 / 视频探测 |
| `POST /open` `POST /reveal` | Finder 打开 / 显示文件 |

### 4.3 下载监控页（127.0.0.1:7799）

- 数据来源：扫描 `~/Downloads` + `~/视频自动搬运发布/生肉视频/` 的媒体文件与 `.part`；合并 daemon history 的 failed 记录；叠加 paused/ignored 状态。
- **状态机**：
  - `downloading`：存在 `.part` 临时文件（`.part/.crdownload/.download/.tmp/.ytdl` 或 `.f\d+\.\w+$` 多流标记）且 mtime 5 分钟内更新过。
  - `stalled`：`.part` 超 5 分钟无变化（显示"下载已中断"，只有删除按钮）。
  - `paused`：在 `.dashboard_paused.json` 中（显示"已暂停"，有继续按钮）。
  - `done` / `failed`：完整文件 / history 中的失败记录。
- 按钮：下载中=暂停+文件夹+删除；已暂停=继续+文件夹+删除；已完成=文件夹+删除；中断/失败=仅删除。
- API：`GET /`、`GET /api/downloads`、`POST /api/reveal`、`POST /api/action`（`pause|resume|delete`）。

### 4.4 点击下载自动打开/聚焦监控页

- daemon 接受下载后自动把监控页带到前台：**优先 AppleScript**（已打开则聚焦该标签，不重复开），失败回退 `open`（会新开标签）。
- **首次需要 macOS 授权**：系统弹窗「Python 想要控制 Google Chrome」→ 点「允许」；连续 3 次失败后本次会话禁用 AppleScript，重启 `com.xiaoer.videolab` 后重新尝试。

### 4.5 已知坑

- YouTube 反爬：`Sign in to confirm you're not a bot` → 换 Clash 节点 / 等消退，勿用 cookie、勿连续重试。
- 慢：代理节点慢（实测 ~0.3MB/s 到 Cloudflare）→ 换节点。
- 重复点击下载会积累监控页标签 → AppleScript 授权后自动聚焦；历史重复标签手动关。
- daemon 重启中断进行中的下载（`.part` 保留可继续）。
- 监控页与 daemon 都无热加载，改代码后必须重启对应服务。

## 五、字幕环节（VideoLingo）

### 5.1 日常用法

1. 浏览器打开 `http://localhost:8501`，左侧粘贴 YouTube 链接，分辨率选 1080p 或 Best，点「Download Video」。
2. 或免粘贴一键：`http://localhost:8501/?youtube_url=<链接>`（带并发锁 `~/videolingo/.oneclick_dl.lock`）。
3. 全自动：下载 → 识别 → 翻译 → 烧录 → 成品复制到 `~/视频自动搬运发布/熟肉视频/`。

### 5.2 本地视频自动导入（生肉视频 → 字幕）

- 监控 `~/视频自动搬运发布/生肉视频/`（下载 daemon 落盘目录），**只处理启动后新出现的文件**（旧文件在 `.auto_import_done.json` 里标记跳过）。
- 流程：新文件等下载稳定（大小两次采样不变 + mtime 超 2s）→ 清空并移入 `~/videolingo/output/` → 写 `input_manifest.json` → 打开 `http://localhost:8501/?auto_process=1` 自动开始处理。
- `output/` 里有未清理旧视频时**等待**（防止覆盖未发布成品）；在页面点「Delete and Reselect」或「Archive to 'history'」后继续。
- 参数：`--watch-dir` 改监控目录、`--keep` 导入后保留原文件、`--no-open` 不自动开浏览器、`--import-existing` 处理已有旧文件、`--reset-state` 清空已见记录。
- 服务：随 `com.videolingo.streamlit` 启停，修改后重启该任务。

### 5.3 竖屏清晰度修复（已实测）

- 原因：`bestvideo[height<=1080]` 按高度过滤，竖屏 1080×1920 被排除，退到 608×1080。
- 修复（`core/_1_ytdlp.py`）：下载前探测方向，竖屏按宽度限制（`width<=1080`），语义=最长边 ≤1080。

### 5.4 补丁与升级

VideoLingo 打了 **4 个本地补丁**（`git pull` 后需按顺序重打；均为未跟踪文件，升级前备份到 `~/videolingo-backup/`）：
1. `本地补丁-自动复制成品.patch`（成品自动复制 + 双语字幕开关）
2. `本地补丁-发布文案.patch`（发布文案生成 + 清晰度修复 + 自动衔接字幕处理；原「抖音发布」补丁已改造，不再含抖音上传）
3. `本地补丁-YouTube一键下载.patch`（URL 参数一键下载 + 并发锁）
4. `本地补丁-本地文件自动导入.patch`（页面支持 `?auto_process=1`）

```bash
cd ~/videolingo
cp config.yaml ~/config.yaml.bak
mkdir -p ~/videolingo-backup && cp *.patch start.sh start_detached.sh ~/videolingo-backup/
git stash -u && git pull
git apply ~/videolingo-backup/本地补丁-自动复制成品.patch
git apply ~/videolingo-backup/本地补丁-发布文案.patch
git apply ~/videolingo-backup/本地补丁-YouTube一键下载.patch
git apply ~/videolingo-backup/本地补丁-本地文件自动导入.patch
git stash pop   # 恢复 config.yaml（冲突时手动合并）
```

- 环境约定：ffmpeg 用 homebrew-ffmpeg tap 9.0（带 libass）；启动带 `NLTK_DISABLE_IMPORT_SECURITY=1` 与代理变量（7897）。
- 注意：`config.yaml`（DeepSeek key）敏感；`start.sh`/`start_detached.sh`/4 个 `.patch` 是未跟踪文件，`git clean -fd` 会丢。
